Team Project 
Software Engineering 
 
Background 
Your software development start-up has been awarded a contract to design and 
implement a prototype operational information system for First Quantum 
Minerals. The objective of this project is to simulate a real-world enterprise 
software development process, from requirements analysis through system 
implementation and documentation. 
Task 
Working in groups, you are required to design, develop, and document an 
operational software system that supports selected business processes of a large 
mining organization. 
The system should be developed using an appropriate programming platform 
such as Python, Java, or C#, and must demonstrate sound application of 
software engineering principles. 
Your project must include: 
• Requirement’s analysis and system specification 
• System design using UML 
• Implementation of core system features 
• Error handling and exception management 
• System testing and validation 
• User and technical documentation 
Deliverables 
1. Operational Software System 
o A functional prototype implementing key system features 
o Developed using Python, Java, or C# (or another approved 
platform)
